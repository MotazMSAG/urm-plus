Multiversal Ren'Py Mod (MRM) for Ren'Py 7.3.5 through 8.5.0

MRM is an independent mod inspired by 0x52's Universal Ren'Py Mod (URM).

Close the game, put URM_fix.bat next to its executable, and choose Install
MRM. You can also drag the game folder onto the BAT. Run the same step to
update. The installer compiles for the game's own engine and writes one
file, game/urmplus.rpa. Start the game and press Alt+U for the MRM menu.

To switch from a combined URM and URM+ installation that predates the separate
urmplus.rpa, move its game/0x52_URM.rpa outside game/ as a backup. If the
combined copy was extracted, move its game/0x52-URM folder out too. Run
Install MRM again. Keep your backups and saves. Leave any original-only
URM copy outside game/ if you want to run MRM on its own.

To remove MRM, close the game and move game/urmplus.rpa out of game/.
Keep your saves. An old original-URM save that refers to original-URM
objects needs either original URM or MRM to read those names.

If you previously used the installer to patch the engine for other
add-ons, the same menu can undo that patch. Installing MRM uses the
game's own compiler and needs no engine patch.
